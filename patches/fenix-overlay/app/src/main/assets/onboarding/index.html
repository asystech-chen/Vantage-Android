Vantage 新用户引导
欢迎

欢迎使用 Vantage

先花一分钟，把外观和常用功能设好。所有选项之后都能改。

  • 基于 Firefox ESR，更新稳定
  • 默认开启跟踪保护，不收集数据
  • 设置随时可改
外观

先让它看起来顺眼

选一套自己喜欢的样子，所有选项都能随时改。

Vantage 主题
蓝系配色，工具栏、菜单和页面使用同一套颜色。
颜色模式
作用于浏览器界面和网页的默认配色。
主题和颜色模式之后也能在 设置 → 外观与定制 里修改。
自定义

自定义你的旅途

挑几个顺手的设置。这里只列常用的，更多在设置面板里。

标签自动休眠
内存紧张时休眠不活跃标签页，需要时再唤醒。
自动检查更新
启动后检查 Vantage 新版本，只提示，不自动安装。
完整列表在 设置 → Vantage。之后随时可以改。
工作区

按项目整理你的标签页

用集合（Collections）把同一项目的标签页收在一起；登录 Mozilla 账号还能在多台设备间同步。

标签页集合
把同一项目的标签页收进集合，在主页可以命名、折叠，再一键打开。
多设备同步
用 Mozilla 账号同步书签、历史和打开的标签页。
集合在主页的标签页菜单里创建；同步在 设置 → 账户 里登录。
隐私

隐私默认已经调好

Vantage 默认使用严格跟踪保护，不需要你在级别之间选择。遇到网站因为保护而显示异常时，可以只对这个网站放宽。

严格保护（默认）
拦截已知跟踪器、跨站 Cookie、指纹脚本和挖矿脚本。不需要额外设置。
自动修复轻微的网站问题
对已知会被跟踪保护弄坏的网站自动放宽，只影响这些站点，不改变全局保护级别。
DNS over HTTPS (DoH)
加密 DNS 查询，默认使用国内可用的 DoH 节点。
单个网站出问题时，点地址栏的盾牌图标，就能只对这个网站关闭保护。
导入与默认

最后一件事

把 Vantage 设为默认浏览器，点击链接时就会直接用它打开。

设为默认浏览器
之后在系统设置里随时可以改回来。
这项随时都能在 系统设置 → 默认应用 里重新操作。

设置完成

这些设置随时都能在 设置 里重新修改。
