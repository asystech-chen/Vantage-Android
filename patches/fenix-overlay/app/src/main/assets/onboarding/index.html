Vantage 新用户引导
欢迎

欢迎使用 Vantage

先花一分钟，把外观和常用功能设好，所有选项之后都能改。

  • 基于 Firefox ESR，更新稳定
  • 默认开启跟踪保护，不收集数据
  • 设置随时可改
外观

先让它看起来顺眼

选一套自己喜欢的样式，所有选项都能随时改。

Vantage 主题
深蓝配色、圆角标签栏，和桌面版使用同一套颜色。
配色模式
作用于界面和浏览器的默认配色。
应用第三方主题时，Vantage 会自动让位，不会覆盖你的主题。
自定义

自定义你的旅途

挑几个顺手的设置，这里只放常用的，更多在设置页面里。

标签自动休眠
一段时间没看的标签会自动收起，省电也省内存。
自动检查更新
启动时检查 Vantage 新版本，只提示，不自动安装。
完整选项都在 设置 → Vantage，之后随时可以改。
隐私

隐私默认已经调好

Vantage 默认使用严格跟踪保护，不需要你在级别之间选择。

严格保护（默认）
拦截已知跟踪器、指纹脚本和隐蔽挖矿脚本，多数站点无需额外设置。
自动屏蔽第三方跟踪器
在严格模式基础上拦截第三方跟踪 Cookie，可以单独为站点放行。
DNS over HTTPS (DoH)
加密 DNS 查询，默认供应商可用性不佳时删除更稳妥的 DNS 解析。
单个站点可临时关闭邮箱保护，直接对该网站免费放行。
扩展

扩展

Vantage 支持安装扩展，全部来自官方的 AMO 扩展商店。

扩展商店
浏览并安装适用于 Android 的扩展。
扩展的安装、更新和停用都在扩展管理器里统一处理。
导入与默认

最后一件事

把 Vantage 设为默认浏览器，点击链接时就会直接用它打开。

设为默认浏览器
之后在系统设置里随时可以改回来。
这项随时都能在 设置 → 默认浏览器 里重新操作。
